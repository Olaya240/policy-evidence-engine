## Two findings worth the coordinator's time

**1. `diverse` and `departments_by_source` are dead (`engine.py:116-117`).**
Both are computed on every call and then read by nothing — the v2 table takes only
`independent_support`, `contradiction_groups` and the dispute counts. It is not
harmful at runtime, but it is actively misleading: a reader sees a diversity
computation immediately above the rule that is supposed to use it, and department
diversity was deliberately dropped from the score. Either delete the two lines or
add a comment saying the value is retained for the trace only — today it reaches
neither the score nor the trace.

**2. `test_same_department_independent_records_are_not_treated_as_diverse`
(`test_engine.py:84-88`) passes for the wrong reason.** It asserts
`confidence < .78`, which was a real discrimination against the old 0.78 diverse
rung. Under the signed table both shapes return `2/3`, so the assertion is true
regardless of department — the test can no longer fail for the reason its name
states. It should either assert equality between the two department shapes (the
honest statement now: diversity does not affect the number) or be renamed.
