## What each test pins

| Test | Contract |
|---|---|
| `test_an_injected_clock_decides_staleness_not_the_wall_clock` | The same record and proposal yield `stale=True` or `stale=False` depending only on the `now=` argument, so staleness is a function of the injected clock |
| `test_the_injected_clock_is_returned_as_the_evaluation_time` | The returned `evaluated_at` is the injected instant, not `datetime.now()` |
| `test_a_future_dated_record_is_not_stale` | `age = (now - timestamp).days` is negative for a future record, and `stale = age > STALE_DAYS` is therefore false |
| `test_exactly_at_the_threshold_is_not_stale_and_one_day_over_is` | The comparison is strict: `STALE_DAYS` exactly is **current**, `STALE_DAYS + 1` is stale |
| `test_partial_days_are_truncated_before_the_comparison` | `timedelta.days` floors, so 90 days and 23 hours still reads as 90 and is **not** stale; one more full day flips it |
| `test_empty_evidence_produces_a_coherent_decision` | `_summarize_status_decision([])` is total: INSUFFICIENT, zero confidence and score, not contested, the two zero-margin rule ids, a non-empty uncertainty string, and every bucket an empty list |
| `test_the_default_clock_is_wall_clock` | Without an argument the clock is timezone-aware and after a fixed 2026-01-01 constant |
| `test_two_engines_with_fixed_clocks_report_their_own_clock` | Injected clocks are per instance and are returned verbatim |

## Deviation from the brief, stated rather than hidden

Item 5 asked for "two engines without a clock differ". I did **not** assert that:
two wall-clock reads can land in the same microsecond, so the assertion would be
flaky for a reason unrelated to the contract. Instead the file proves the default
is wall clock (after a past constant) and, in the contrast case, that injected
clocks are per instance. If the coordinator wants the literal assertion, sample
the default clock N times and assert `len(set(samples)) > 1` — still timing-based.
