# Slice 7, worker 5 — contracts for `investigate` and `challenge`

Range: `app/engine.py:207-412` (the slice the coordinator assigned). Test file:
`backend/tests/test_engine_slice7_contracts.py`, eleven cases.

## What each case pins, and the code it rests on

| # | Contract | Where the code decides it |
|---|---|---|
| 1 | `investigate` leaves the caller's records byte-identical and in order | `_claim` only reads `records` (`indexed = {r.id: r for r in records …}`) and passes them to the boundary; no field is assigned |
| 2 | `challenge` leaves the caller's claim dict byte-identical, and returns version + 1 with a disputed item | `raw = current.copy()`, then `raw["evidence"]` is rebuilt from copies (`dict(item, disputed=True)` / `dict(item)`); the in-code comment records that the earlier aliasing let the semantic guard write into the caller's `expected_claims` |
| 3 | unknown record id is refused | `record is None` → `AssessmentError("Source record was not found")` |
| 4 | quote absent from the record is refused | `quote not in record.text` → `AssessmentError("Challenge quote must be an exact source substring")` |
| 5 | a two-character quote that *does* occur is refused | the same condition's `len(quote.strip()) < 3`; `"is"` occurs inside "checklist", so only the floor can refuse it |
| 6 | zero records → one claim per hypothesis, all INSUFFICIENT, no evidence | `investigate` builds one claim per `HYPOTHESES` entry; an empty evidence list reaches the table as 0:0 |
| 7 | two clocks change `evaluated_at` and `generated_at` but not status or confidence | `now = self.clock()` feeds `_validate_assessment_with_time`, and `generated_at = evaluation_times[-1]` |

## Read-only observations worth carrying into the slice

1. **Both refusals share one code.** `AssessmentError` defaults to
   `code="invalid_assessment"`, and neither challenge message passes a code, so a
   missing record, a restricted record and a non-matching quote are
   indistinguishable to a caller that reads `code`. This is the same code-reuse
   shape slices 1 and 4 already fixed twice (`request_too_large`,
   `unsupported_transport`). Not changed here: it is the module's public error
   contract, not this worker's file.
2. **`len(quote.strip()) < 3` and `quote not in record.text` measure different
   strings.** Membership uses the raw quote, the floor the stripped one, so
   `" the"` and `"the"` take different paths for the same evidence.
3. **`investigate([])` is the only path that yields INSUFFICIENT without any
   provider proposal being refused** — every other INSUFFICIENT in the suite
   comes from an abstaining provider, so the empty-corpus path was untested.
